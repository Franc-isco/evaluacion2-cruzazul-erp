# Evaluación 4 - Cruz Azul ERP

Proyecto correspondiente a la Evaluación N°4 de la asignatura TI3053_N5_C2.

## Objetivo

Implementar una arquitectura en AWS para el sistema ERP de Farmacias Cruz Azul, incorporando balanceo de carga, Auto Scaling, monitoreo con CloudWatch, autenticación segura y base de datos PostgreSQL bajo modelo IaaS.

## Servicios principales

- Amazon EC2
- Amazon Machine Image AMI
- Elastic Load Balancing
- Auto Scaling Group
- Amazon CloudWatch
- Amazon S3
- PostgreSQL en Docker
- Node.js + Express
- JWT / MFA
